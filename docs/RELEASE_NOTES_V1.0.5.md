# DSH 备份与恢复 v1.0.5

适用 DSH 版本：0.2.2-rc.5（开发/测试所用版本）
最低兼容版本：>= 0.2.2-rc.5（由插件 engines.dsh 强制校验）

## 系统支持

- **当前版本仅在 Windows 11 上提供支持与验证。**
- Windows 10、macOS、Linux、Windows Server、Windows on ARM 及其他环境**未支持、未验证**，
  请不要将其视为可用环境。
- DSH 桌面端要求 `>= 0.2.2-rc.5`；本版本开发和测试使用 `0.2.2-rc.5`。
- Node.js 要求 `>= 20`（由 DSH 自带运行时提供）。
- 离线恢复使用 Windows 11 自带的 Windows PowerShell 5.1，不需要额外安装。

## 主要安全改进

- 离线恢复程序（`restore.ps1`）新增 Windows **Reparse Point（符号链接 / 目录联接）安全检查**。
- 检查覆盖：`DSH_HOME`、备份源路径、恢复目标路径、回滚路径、递归复制路径，以及 ZIP 解压实际创建的临时目录与目标路径。
- 检测到不允许的重解析点，或无法安全确认相关路径属性时，恢复会**中止**。
- 保留原有的还原点 ID 校验、词法边界检查与 ZIP 条目校验。
- 不改变现有备份格式与恢复复制逻辑；离线程序的 `$ScriptVersion` 同步为 1.0.5。

## 测试与验证

- A2-R1 专项测试：22 PASS / 0 FAIL / 1 SKIP。
- A2 专项测试：56 PASS。
- Node 原有测试：136 PASS。
- 合计：214 PASS / 0 FAIL / 1 SKIP。
- 真实 Windows Junction 场景已在隔离临时目录中测试。
- 测试环境：Windows 11 + Windows PowerShell 5.1。

## 未验证场景与残余风险

- Symlink 场景未动态验证，测试中跳过 1 项。
- ACL 权限拒绝场景未动态构造，未动态验证。
- 当前路径检查不能彻底消除本地 TOCTOU 竞争风险。
- 不宣称已彻底消除路径穿越、路径逃逸或所有文件系统安全风险。
- 不建议在 `DSH_HOME` 或备份目录内放置符号链接 / 目录联接。

## 兼容性

- 保留 V1.0.4 的 manifest 兼容性；不改变现有备份格式。
- 旧还原点不需要迁移，也不需要修改旧 `manifest.json`。
- 不扩大支持范围：仍仅支持 Windows 11。
- DSH 最低版本仍为 `>= 0.2.2-rc.5`。
- Node.js 要求仍为 `>= 20`。
- 离线恢复仍使用 Windows PowerShell 5.1。

## 备份位置与数据安全

- 备份目录位于 DSH 工作区内；删除、移动、格式化或损坏该工作区，可能导致其中的备份及还原点丢失。
- 删除工作区前，请先把 `dsh-backups` 迁移到其他工作区。
- 插件不会自动选择、合并、迁移、覆盖或删除任何备份目录；多个目录需要用户手动处理。
- 完整 8 条责任说明请阅读 [README 的数据安全与免责声明](../README.md#7-数据安全与免责声明)。

## 升级

1. 下载 V1.0.5 发布页提供的 Source code (zip)，解压后选择直接包含 `package.json` 的目录，按 README 中的原有方式更新或重新添加插件；
2. 打开一次插件页，让 `dsh-backups/restore.ps1` 刷新到 1.0.5；
3. 原有还原点继续保留，无需迁移旧备份；
4. 不需要修改旧 `manifest.json`；
5. 使用离线恢复前仍须完全退出 DSH。

## 说明

- 日志仅保存在本机，不会上传；分享日志前请检查是否含用户名或路径。
- 登录凭据默认不备份；勾选后为明文，请勿分享或提交还原点目录。

- 离线恢复程序仅支持 Windows 11；应用内备份/恢复的支持范围同样以 Windows 11 为准。
