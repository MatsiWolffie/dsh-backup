# DSH 备份与恢复 v1.0.2

> 历史版本说明：该版本发布时的平台描述已过时；当前版本仅支持 Windows 11，见当前 README。

适用 DSH 版本：0.2.2-rc.5（开发/测试所用版本）
最低兼容版本：>= 0.2.2-rc.5（由插件 engines.dsh 强制校验）

## 新增

- **本地诊断日志**：操作记录写入 `dsh-backups/logs/plugin.log`，单文件约 512 KB 后滚动为 `.log.1`，
  只保留一份旧文件。记录备份/恢复/删除的开始结束、还原点 ID、文件数/字节、耗时、
  失败部分与错误原文、挂载状态、HTTP 拒绝与工具错误。
  **不记录**登录凭据、会话/附件内容或请求体。
- **离线恢复日志**：`dsh-backups/logs/restore-offline.log`，记录程序版本、选择、
  每部分结果、错误与退出码。
- **卡片「诊断」区**：一键复制诊断信息（插件/DSH 版本、路径、挂载状态、上次恢复、最近日志，
  主目录显示为 `%USERPROFILE%`）和打开日志文件夹。
- 故障排查文档补充日志位置、分享前检查事项。

## 修复

- 离线恢复在 `-Point` 指向无效路径/压缩包时给出友好提示并写入日志；
  菜单取消、无还原点、序号越界也会记录退出原因。
- 诊断/日志写入失败不会覆盖原始操作错误。
- 诊断信息兼容离线恢复写入的回执（UTF-8 BOM、单元素数组被折叠为对象）。

## 升级

1. 下载下方 **Source code (zip)**，按原方式重新添加插件；
2. 打开一次插件页或做一次备份，让 `dsh-backups/restore.ps1` 刷新到 1.0.2；
3. 日志出现在 `dsh-backups/logs/`。

## 说明

- 日志仅保存在本机，不会上传；分享日志前请检查是否含用户名或路径。
- 离线恢复程序仍仅限 Windows；当前平台支持范围以 README 为准（当前仅支持 Windows 11）。
- 还原点包含会话与附件等私有数据，请勿分享。
