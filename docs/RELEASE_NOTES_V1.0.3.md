# DSH 备份与恢复 v1.0.3

适用 DSH 版本：0.2.2-rc.5（开发/测试所用版本）
最低兼容版本：>= 0.2.2-rc.5（由插件 engines.dsh 强制校验）

## 修复

- **备份位置固定**（#2）：首次使用后把备份位置写入
  `%USERPROFILE%\.dsh\.dsh-backup\location.json`，之后新增或切换工作区都不会再改变备份目录；
  升级时会优先沿用“已经存在还原点”的工作区，旧备份不会看起来“丢失”。
- 如果原工作区已经从 DSH 删除：先把原文件夹重新添加为工作区一次，插件会自动找回旧备份并固定位置。
- 插件页和诊断信息会显示当前备份位置；诊断信息新增「备份位置来源」，便于排查同类问题。

## 升级

1. 下载下方 **Source code (zip)**，按原方式重新添加插件；
2. 打开一次插件页，让 `dsh-backups/restore.ps1` 刷新到 1.0.3；
3. 从 1.0.2 升级无需迁移备份；旧备份仍保留在原工作区的 `dsh-backups`。

## 说明

- 日志仅保存在本机，不会上传；分享日志前请检查是否含用户名或路径。
- 离线恢复程序仍仅支持 Windows；应用内备份/恢复跨平台可用。
- 还原点包含会话与附件等私有数据，请勿分享。
