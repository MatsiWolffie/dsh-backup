# DSH 备份与恢复 v1.0.4

适用 DSH 版本：0.2.2-rc.5（开发/测试所用版本）
最低兼容版本：>= 0.2.2-rc.5（由插件 engines.dsh 强制校验）

## 变更

- 备份目录改为每次重新检索 DSH 已注册工作区和当前工作区服务，移除 `location.json` 固定路径依赖。
- 仅当恰好存在一个可访问的 `dsh-backups` 时自动使用；
  没有时在可访问的合适工作区创建。
- 存在两个或更多 `dsh-backups`，或任一已注册工作区无法检查时，停止自动选择，
  阻断备份、恢复、删除；不自动选择、合并、迁移、覆盖或删除任何目录。
- 插件页显示全部候选路径和无法检查的工作区，并提供「重新检索」。
- README 增加醒目数据风险警示；旧 `location.json` 不再读取。
- 不修改备份格式与恢复复制逻辑；离线程序仅同步版本号到 1.0.4。

## 升级

1. 下载下方 **Source code (zip)**，按原方式重新添加插件；
2. 打开一次插件页，让 `dsh-backups/restore.ps1` 刷新到 1.0.4；
3. 从 1.0.3 升级无需迁移备份；旧备份仍在原工作区的 `dsh-backups`。

## 注意事项

- 如果已经存在多个 `dsh-backups`（例如测试工作区残留），插件会停止自动选择；
  请手动把多余目录移出 DSH 工作区，只保留一个，再点「重新检索」。
- 如果某个已注册工作区路径不可访问，插件也会阻断，直到该工作区恢复或从 DSH 移除。
- 插件只能检索 DSH 已注册工作区和当前工作区服务；未注册的任意磁盘目录不会被全盘扫描。

## 说明

- 日志仅保存在本机，不会上传；分享日志前请检查是否含用户名或路径。
- 离线恢复程序仍仅支持 Windows；应用内备份/恢复跨平台可用。
- 还原点包含会话与附件等私有数据，请勿分享。
